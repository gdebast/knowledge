# Lab concepts

One file per concept, created by `/learn-analyze` (or by hand).

- `<name>.tsx` - React demo with `export default function Demo()`, shown in the
  lab app: `npm run dev`, then pick it in the left menu.
- `<name>.ts` - plain TypeScript, run it with `npx tsx src/concepts/<name>.ts`.

Follow the `// TRY:` comments: predict the result first, then run.
